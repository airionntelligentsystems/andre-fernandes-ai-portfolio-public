# Relato de problemas

Não publique credenciais ou dados pessoais em issues. Para comunicar um problema no laboratório, descreva o comportamento sem informações sensíveis pelo contato profissional disponível no [LinkedIn](https://www.linkedin.com/in/andre-ffernandes/).

O laboratório contém somente exemplos fictícios. A documentação explicita os controles demonstrados e os requisitos que permanecem fora do escopo de produção.
