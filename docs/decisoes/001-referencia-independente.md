# Decisão 001 — Laboratório independente dos produtos

**Status:** adotada.

**Contexto:** demonstrar qualidade de engenharia sem distribuir implementação proprietária ou dados de clientes.

**Decisão:** construir uma referência pequena, com domínio fictício, corpus sintético e histórico Git próprio. O material comercial não é exportado nem usado como fixture.

**Consequência:** o código público é demonstrativo e pode ser observado ou copiado. As provas não devem ser apresentadas como validação do produto comercial.
