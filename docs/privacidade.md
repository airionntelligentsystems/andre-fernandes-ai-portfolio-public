# Fronteira de divulgação

Este repositório foi construído separadamente dos projetos comerciais. Seu conteúdo demonstrativo foi escolhido para ser compartilhável.

## Material incluído

Perfil profissional, sínteses de projetos reais sem conteúdo confidencial, diagramas abstratos, decisões de engenharia, dados fictícios, código independente e evidências locais das referências técnicas.

## Material mantido fora do portfólio

Dados de pacientes, hóspedes e clientes; credenciais; prompts de produtos; exportações n8n; regras comerciais; schemas e endpoints reais; topologia de produção; contratos; planos comerciais; backups e logs operacionais.

## A publicação é uma fronteira

Material público pode ser copiado. O portfólio não é um mecanismo de impedir cópia. Repositórios privados de produtos e este laboratório são mantidos separados. Antes de publicar novos arquivos, revisar também histórico Git, referências, metadados, logs e artefatos.

Referências: [visibilidade de repositórios](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility) e [remoção de dados sensíveis](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).
